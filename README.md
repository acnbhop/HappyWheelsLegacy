# HappyWheelsLegacy
This is a fork of https://github.com/Afterflash/HappyWheels aimed to improve and support the legacy Flash version of Happy Wheels.

# Building
1. Run `npm i` to install prerequisites.
2. Use `npm run build` to build the SWF file.
3. Done!

# Running
Use `npm run start` to launch into the game.
